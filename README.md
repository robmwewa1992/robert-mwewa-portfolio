# Robert Mwewa — Personal Portfolio

A responsive, static personal website built with HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` — homepage and featured projects
- `about.html` — profile, values, and interests
- `work.html` — selected projects
- `journal.html` — notes and articles
- `contact.html` — contact details and sample email form

## Run locally

Open `index.html` in a browser, or serve this folder with a local static web server and visit its address.

## Customize

Edit the HTML files to update the page copy, project examples, and contact details. Shared layout and responsive styles are in `styles.css`; the mobile navigation and current-year footer are in `script.js`. The contact form uses a sample `mailto:` address and should be updated before use.
